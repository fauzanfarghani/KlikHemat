# Klik Hemat ⚡️

**Klik Hemat** is a smart, modern, and user-friendly energy management application built with **Flutter**. The app aims to help users efficiently track, identify, and optimize their daily electrical consumption to reduce overall electricity costs.

## ✨ Features

- **🔐 Secure Authentication**: Seamless Sign-up and Login integration with Firebase Authentication.
- **📱 Modern & Premium UI**: Features a beautiful, custom-designed interface utilizing shadow cards, vivid gradients, and modern typography (Poppins).
- **🔌 Electrical Tracking**: Add, classify, and track all electronic appliances in your household. Includes duration of use, power limits (wattage), and real-time active status management.
- **💡 Smart Consumption Calculator**: Analyzes daily electrical usage data and provides a comprehensive breakdown of active consumption parameters.
- **🎯 Energy Saving Recommendations**: Suggests personalized, actionable advice and smart practices to lower daily electrical footprints and save energy blocks.
- **👤 Profile Customization**: An intuitive, structured profile view handling account settings, profile pictures, and secure credential handling.

## 🛠 Tech Stack

- **Frontend Core**: [Flutter](https://flutter.dev/) & Dart.
- **Backend & Database**: Firebase (Authentication, Realtime Database / Firestore, Storage).
- **Typography & Icons**: Google Fonts (Poppins), Cupertino Icons, and fully customized natively-injected launcher icons.
- **Assets**: Embedded local placeholder imagery and modern gradient vectors.

## 🚀 Getting Started

If you want to run this application locally, ensure you have Flutter and the necessary SDK environments installed.

### Pre-requisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.4.4 or above)
- iOS Simulator or Android Emulator
- Active Firebase Project Setup (GoogleServices-Info.plist / google-services.json)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/klik_hemat.git
   ```
2. Navigate into the directory:
   ```bash
   cd klik_hemat
   ```
3. Get the required pub dependencies:
   ```bash
   flutter pub get
   ```
4. Run the application:
   ```bash
   flutter run
   ```
